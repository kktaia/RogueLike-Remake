# RogueLike Remake

C++ と DxLib で開発している、ダンジョン探索型ローグライクのリメイクです。[旧作 RogueLike](https://github.com/kktaia/RogueLike) をもとに、探索画面やプログラムの構造を作り直しています。現在は開発途中で、探索の基盤を中心に実装しています。

## 現在の機能

- 部屋と通路からなる 48×32 マスのダンジョンをランダム生成
- 4方向への移動と、階段から次の階層へ進む機能
- プレイヤーを追うカメラ、部屋・通路に応じた暗闇、ミニマップ
- HP・満腹度・所持金の表示と、移動ターンに応じた満腹度の減少
- メニューとメッセージウィンドウ

## 操作

- 矢印キー：移動、メニューの選択
- Shift：メニューを開く
- Enter：メニューの決定

## 旧作からの変更

旧作には敵との戦闘、アイテム、状態異常、ボスやクリア条件があります。リメイク版はこれらをすべて再実装した完成版ではなく、まず探索の仕組みを作り直したものです。

- **コードの役割分担**：フィールド、プレイヤー、カメラ、UI、メニューなどを分け、機能を追加・変更しやすい構成を目指しています。
- **探索画面の再設計**：プレイヤー追従カメラ、暗闇の表現、ミニマップ、ステータス表示を組み合わせています。
- **ターン処理の分離**：移動に伴うターン経過を `TurnManager` で通知する仕組みを設けています。

## 開発状況と今後の課題

敵・戦闘・アイテム・状態異常は、現行のリメイク版にはまだ実装されていません。メッセージ履歴やミニマップの探索範囲の制限も未完成です。移動途中でキーを離すと移動が止まる挙動の改善も予定しています。

## ビルド環境

- Windows、Visual Studio の C++ 開発環境（プロジェクトのツールセット設定は `v145`）
- C++20、Windows SDK、[DxLib](https://dxlib.xsrv.jp/)
- `dx1.sln` を開いてビルドします。Win32 構成では DxLib のインクルード・ライブラリパスに `../DxLib` が設定されています。環境に合わせてパスを調整してください。x64 構成では別途 DxLib の設定が必要です。
- 実行時はプロジェクトフォルダを作業ディレクトリにし、`Graphic` フォルダを参照できるようにしてください。
- 現在のコードは `Graphic/WorkSans-Bold.ttf` を参照しますが、フォントは `Font/WorkSans-Bold.ttf` にあります。フォントを使うには読み込み先を合わせてください。
